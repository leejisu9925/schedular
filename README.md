# ✨🐥🍀 통합 스케줄러 & 투두 (PWA Handoff Package)

본 핸드오프 패키지는 확정된 디자인 및 PWA(Progressive Web App) 기능이 적용된 소스 코드 모음입니다.

## 📁 구성 파일
- `index.html`: 메인 웹 애플리케이션 및 스케줄러 UI
- `manifest.json`: PWA 앱 설정 파일 (앱 이름, 테마 색상, 아이콘 등)
- `sw.js`: 오프라인 접속 및 데이터 캐싱을 위한 서비스 워커 스크립트
- `README.md`: 가이드 문서

## 🚀 실행 및 모바일 설치 방법
1. 웹 서버 또는 무료 호스팅(GitHub Pages, Vercel 등)에 본 폴더의 파일들을 업로드합니다.
2. 모바일 브라우저(Safari 또는 Chrome)로 해당 웹 URL에 접속합니다.
3. 브라우저 메뉴에서 **'홈 화면에 추가'**를 누르면 모바일 앱 형태로 바로 설치 및 사용할 수 있습니다.
